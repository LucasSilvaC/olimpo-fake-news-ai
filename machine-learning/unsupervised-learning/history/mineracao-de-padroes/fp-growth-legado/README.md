# FP-Growth legado

Estes experimentos são históricos. O [principal atual](../../../fp_growth_principal_sem_autoria.ipynb) usa `sintaxe_ampliada`.

- [Baseline com autoria](fp_growth_baseline_com_autoria.ipynb): 31 padrões frequentes, 28 regras direcionais elegíveis e 21 padrões com autoria. Usa seis medidas de estilo/autoria nos primeiros 300 caracteres.
- [Antigo principal sem autoria e controles](fp_growth_principal_sem_autoria_controles.ipynb): 10 padrões frequentes e oito regras elegíveis. Compara os resultados dentro dos estratos de autoria.
- [Avaliação histórica com autoria](avaliacao_fp_growth_com_autoria.ipynb): incidência posterior dos padrões congelados nas classes.

Os [resultados históricos](RESULTADOS.md) preservam contagens, controles e limites. Autoria tem forte associação à classe no corpus. As medidas legadas também têm dependência matemática entre TTR, diversidade e pontuação. Esses resultados não oferecem classificação factual de notícias novas.

Execute os notebooks em um kernel Python 3 a partir de uma pasta do repositório. A leitura do corpus e dos outputs usa a raiz `machine-learning`. As cópias idênticas antes existentes na raiz foram retiradas, preservando os notebooks desta pasta.
